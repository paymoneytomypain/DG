① WebGLシェーダー負荷（レイマーチング・フラグメントシェーダー全画面計算）WebGL / GPU or SwANGLE

GLSLのフラグメントシェーダーで球のレイマーチングを毎ピクセル計算します。GPU無効化・SwANGLE(CPU)固定時はFPSが大きく低下します。反復回数を上げるほど負荷が増えます。

② Canvas2Dパーティクル負荷（加算合成・軌跡描画）Canvas2D / disable-accelerated-2d-canvas 対象

加算合成(globalCompositeOperation)とぼかしを伴う多数のパーティクルを毎フレーム再計算・再描画します。CPU描画時はパーティクル数を上げると顕著にFPSが落ちます。

③ CSS 3D合成負荷（transform / filter / box-shadow 大量アニメーション）Compositing / disable-gpu-compositing 対象

112個の要素をそれぞれ独立して3D回転・拡縮・box-shadowアニメーションさせ、レイヤー合成の負荷をかけます。DirectComposition/GPUコンポジット無効時の挙動確認に使えます。
